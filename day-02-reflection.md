
# Day 02 Reflection

1. Difference between HTML tag, element and attribute:
A tag is written inside angle brackets. An element includes the opening tag, content and closing tag. An attribute provides extra information about an element.

2. When should you use an ordered list?
Use an ordered list when items need to follow a particular order or sequence.

3. Why does an image need alt text?
Alt text describes the image when it cannot load and helps screen readers.

4. What happened when I broke an internal link?
The link did not jump to the correct section because the href and id did not match. I fixed it by restoring the correct id.
