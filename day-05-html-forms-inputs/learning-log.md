
# Day 05 Learning Log

## What I Built
I created a student registration demo form using HTML.

## Two Validation Checks
1. Empty required fields show browser validation.
2. Invalid email addresses are not accepted.

## Bug Fixed
I temporarily changed a label's for value. The label stopped connecting to the correct input. I fixed it by matching the for and id values.

## Why Client-Side Validation Is Not Enough
Users can bypass browser validation. A real application must validate data again on the server.

## One Future Improvement
I would connect the form to a database to save registration details.
